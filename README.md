# MIRAGE v1.1.0 Manuscript Analysis

This repository contains the analysis scripts and supporting resources used to produce the analyses, tables, figures, and validation materials for the MIRAGE v1.1.0 manuscript that is currently under review.

The repository is intended to support reproducibility of the manuscript analyses. The MIRAGE database dataset itself is distributed separately through Zenodo.

## Repository Structure

```text
MIRAGE-analysis/
├── code/            MATLAB scripts used for manuscript analyses
├── data/            Local copy of MIRAGE data used by the scripts
├── figures/         Figures generated by the analysis scripts
├── NaturalEarth/    Natural Earth geographic data used for mapping
├── results/         Tables and other generated analysis results
├── validation/      Validation data and generated validation materials
├── README.md
├── CHANGELOG.md
└── LICENSE
```

The `data`, `figures`, `results`, `NaturalEarth`, and `validation` directories may be populated automatically when the analysis scripts are run.

## MIRAGE Database

The analyses use **MIRAGE Metabase v1.1.0**.

The complete database is distributed through the corresponding Zenodo release rather than through this GitHub repository. Analysis scripts automatically download the required MIRAGE Parquet file from the version-specific Zenodo record if it is not already present in the local `data` directory.

**Zenodo record:** `21891580`

The scripts are configured to use the following local file:

```text
data/MIRAGE.parquet
```

Researchers may also place a compatible local copy of the dataset at this location before running the scripts. If the file is already present, the scripts will use the local copy rather than download it.

## Software Requirements

The analyses were developed and tested using **MATLAB R2025b**.

The scripts use functionality available in recent MATLAB releases, including:

* `parquetread`
* `readgeotable`
* `webread`
* `websave`
* `exportgraphics`
* geographic plotting functions such as `geoaxes` and `geoplot`
* `bubblechart` and `bubblelegend`
* `binofit` for binomial confidence intervals

Some scripts may require additional MATLAB toolboxes depending on the specific analysis.

Earlier MATLAB releases may work for individual scripts but have not necessarily been tested. Where practical, scripts use fallback functionality to improve compatibility across MATLAB versions.

## External Geographic Data

Several analyses and figures use **Natural Earth** geographic boundary data.

The required 10m country and first-level administrative boundary files are:

```text
ne_10m_admin_0_countries.json
ne_10m_admin_1_states_provinces.json
```

These files are downloaded automatically if they are not already present in the `NaturalEarth` directory.

The scripts retrieve the files from the public `natural-earth-geojson` repository:

```text
https://github.com/martynafford/natural-earth-geojson
```

Natural Earth geographic data are not committed to this repository because of their size. The scripts therefore treat them as an external dependency and download them when needed.

For reproducibility, the analysis scripts should be used with the Natural Earth version specified in the manuscript/repository documentation.

## Running the Analyses

1. Clone or download this repository.
2. Open MATLAB.
3. Set the repository's `code` directory as the working directory, or open the desired script directly.
4. Run the analysis scripts in the order required for the manuscript analyses.

The scripts determine the repository root automatically from their own location. They therefore do not depend on the absolute paths used on the author's computer.

For example:

```matlab
codeDir = fileparts(mfilename('fullpath'));
repoDir = fileparts(codeDir);
```

This allows the repository to be moved to another computer without modifying hard-coded local paths.

### Automatic Dependencies

When required files are not present locally, scripts may automatically download:

* MIRAGE v1.1.0 from Zenodo
* Natural Earth geographic boundary files from the public GitHub repository

Downloaded data are stored in the appropriate repository directories.

## Reproducibility

The analysis scripts are designed to reproduce the manuscript's reported:

* geographic coverage statistics (Table 1)
* validation analyses (see Technical Validation)
* manuscript figures (Figs 2-3)
* source-overlap analyses
* other derived results documented in the manuscript

Generated files are written to the `figures` and `results` directories, while validation materials are written to `validation`.

The exact scripts, data version, and external geographic resources corresponding to the manuscript submission should be preserved with the associated release/version of this repository.

## Validation

The `validation` directory contains materials associated with validation of MIRAGE metadata matching.

Validation tables may contain manually reviewed events and corresponding source-matching judgments. These materials are used to evaluate the relationship between MIRAGE matching confidence and observed matching precision.

## Versioning

This repository corresponds to the **MIRAGE v1.1.0** database and manuscript analyses.

The analysis code and dataset are versioned separately:

* **GitHub:** manuscript analysis code and reproducibility resources
* **Zenodo:** MIRAGE database release

The repository's `CHANGELOG.md` documents substantive changes to the analysis code across releases.
